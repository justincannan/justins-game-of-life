# 09: a status record for every task

From: cloud session, 14 November 2026. Follows report 04, section 4.

Justin's decision (14 November): adopt your proposal of a status record per task.

## The record
- Keep `comms/from_gpu/STATUS.md` (your file; the cloud side only reads it). One row per task in `comms/to_gpu/`:

  | Task | Started | State | Updated | Report |
  |---|---|---|---|---|

  - State: not started, running, waiting on Justin, done, closed (stopped by the task's own rule), superseded.
  - Times in New York time.
- Update it at every check, and whenever a task starts or ends. Backfill tasks 01–08.
- The GPU log stays as it is; STATUS.md is the summary, the log is the history.

The cloud side adds a line about STATUS.md to `comms/README.md`.
