# Justin's Game of Life: rules for every Claude session in this repository

Two kinds of session work here:
- the **cloud** session (claude.ai) and its scheduled checks: design, the page's code, notes;
- the **gpu** session (Claude Code on Justin's GPU machine): measurements, validations, heavy runs.

Read `comms/README.md` for how they talk, and `THEORY_NOTES.md` for the project's decisions and proposals.

## Standing rules (Justin's)
- Justin decides. Record his decisions as decisions and Claude's ideas as proposals, in THEORY_NOTES.md and in reports.
- Emergence, not scripts. Readouts are measures, not causes.
- Broad biological accuracy, not strict; no real organic chemistry; not modelling real bacteria. Check biological claims
  against sources, and quote sources only briefly.
- Anything shared with other people is written by Justin; Claude writes notes.
- `build/justins_game_of_life.html` is generated. Change `tools/` and rebuild (README.md), then syntax-check the script.
- Never put copyrighted book text in the repository.
- Commits end with the attribution lines the session is given.
